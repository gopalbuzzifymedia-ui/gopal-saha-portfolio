# Gopal Saha — Responsive Portfolio Website

Next.js + Tailwind CSS portfolio website for a Scientific Illustrator & Graphic Designer.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production build

```bash
npm run build
npm start
```

## Included
- Responsive mobile / tablet / desktop layout
- Hero section
- Filterable project gallery
- About section
- Services / capabilities
- Contact CTA
- Portfolio images from the supplied project collection
